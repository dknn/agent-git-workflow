# agent-git-workflow

## Superseded by skills-git-workflow

This repository is no longer maintained. It has been replaced by
[**dknn/skills-git-workflow**](https://github.com/dknn/skills-git-workflow).

Use the replacement repository for installation instructions, updates, and the
`git-workflow` skill:

- `gitc`: review and scan approved changes, then create a local commit.
- `gitship`: commit when needed, push a branch, and create and merge a GitHub
  pull request or GitLab merge request when repository protections allow it.

Install `git-workflow` from `skills-git-workflow` only. You do not need to
install this repository as well.

This repository is retained for historical reference. Please direct issues and
contributions to [skills-git-workflow](https://github.com/dknn/skills-git-workflow).
